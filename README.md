# Live Weather Dashboard

## Description
A responsive Live Weather Dashboard developed using HTML, CSS, and JavaScript. It displays current weather details and a 5-day weather forecast for searched cities.

## Features
- Search weather by city name
- Display current temperature
- Show humidity and wind speed
- Display weather conditions
- 5-day weather forecast
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Open-Meteo API

## Project Files
- `index.html` – Website structure
- `style.css` – Website design
- `script.js` – Weather API and functionality

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Search for a city to view its weather.

## API
This project uses the Open-Meteo Geocoding API and Weather Forecast API. An API key is not required.

## Note
An internet connection is required to fetch live weather information.
